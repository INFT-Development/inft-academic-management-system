# INFT Academic Management System

## Overview

The INFT Academic Management System is a centralized platform designed to streamline attendance management, academic communication, student engagement, and administrative workflows for the Information Technology Department.

## Tech Stack

- Next.js (Web)
- React Native + Expo (Mobile)
- FastAPI (Backend)
- PostgreSQL (Database)

## Modules

- Authentication
- Attendance Management
- Timetable Integration
- Forms & Activities
- Feedback
- Assignment Tracking
